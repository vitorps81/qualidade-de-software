# 2. Propostas de Melhoria Ágil

| Melhoria Proposta                                                       | Metodologia Relacionada                              | Benefício Esperado                                                  |
| ----------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------- |
| Utilizar um quadro Kanban para acompanhar as atividades                 | Kanban                                               | Melhor visualização do andamento do projeto.                        |
| Realizar revisões periódicas das funcionalidades desenvolvidas          | Scrum                                                | Identificação mais rápida de problemas e oportunidades de melhoria. |
| Adotar programação em pares quando o projeto for desenvolvido em equipe | XP (Extreme Programming)                             | Redução de defeitos e compartilhamento de conhecimento.             |
| Definir critérios de entrada e conclusão para cada funcionalidade       | Definition of Ready (DoR) e Definition of Done (DoD) | Maior padronização e qualidade nas entregas.                        |

---

# 3. Definition of Ready (DoR)

Antes de iniciar o desenvolvimento de uma funcionalidade, ela deverá atender aos seguintes critérios:

* O requisito está claramente definido.
* Os critérios de aceitação foram especificados.
* O objetivo da funcionalidade está compreendido.
* Os recursos necessários estão disponíveis.
* Não existem dúvidas que impeçam o início do desenvolvimento.

---

# 4. Definition of Done (DoD)

Uma funcionalidade será considerada concluída somente quando atender aos seguintes critérios:

* A implementação foi finalizada.
* Os critérios de aceitação foram atendidos.
* Os testes unitários e funcionais foram executados com sucesso.
* Não existem defeitos conhecidos que impeçam o uso da funcionalidade.
* A documentação necessária foi atualizada.
* A funcionalidade está pronta para entrega.

---

# ✅ Conclusão

A aplicação de práticas ágeis no projeto LocalEats demonstrou que organização, planejamento e melhoria contínua são fundamentais para garantir a qualidade do processo de desenvolvimento. A utilização de conceitos como Kanban, Scrum, XP, Definition of Ready e Definition of Done contribui para tornar o fluxo de trabalho mais previsível, reduzir falhas e aumentar a qualidade das entregas.

Mesmo em um projeto desenvolvido individualmente, essas práticas auxiliam na organização das atividades, facilitam o acompanhamento da evolução do projeto e tornam o desenvolvimento mais eficiente e estruturado.
